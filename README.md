# Laboratorio

Base reutilizable con Django 5.2 y PostgreSQL.

## Inicio rápido

1. Crea y activa un entorno virtual.
2. Ejecuta `pip install -r requirements.txt`.
3. Copia `.env.example` como `.env` y ajusta PostgreSQL.
4. Ejecuta `python manage.py makemigrations` y `python manage.py migrate`.
5. Inicia con `python manage.py runserver`.
